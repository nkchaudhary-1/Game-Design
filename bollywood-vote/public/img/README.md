# Stage backdrop (optional)

Put your backdrop picture in this folder and name it **`backdrop.jpg`** (or `backdrop.png` / `backdrop.webp`).
If it is there, the site uses it behind everything; if not, the site shows its plain stage glow.

* Best size: 16:9, about 1920 x 1080. A JPG of 200 to 500 KB loads fast on phones.
* The picture is fitted to the top of the screen, so keep the title sign in the top centre.
* On phones the picture is cropped to the lower stage area, so the sign is never cut in half.
* The host screen hides its own text title when the picture is present, because the sign in the picture is the title.
